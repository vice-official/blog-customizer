# 📝 Blog Customizer

Интерактивное веб-приложение, позволяющее настраивать внешний вид статьи в режиме реального времени с помощью сайдбара.

---

## Возможности

-  Настройка шрифта
-  Изменение размера текста
-  Выбор цвета текста и фона
-  Управление шириной контента
-  Сброс настроек
-  Применение изменений по кнопке
